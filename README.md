# 💻 Programs

The repository contains different Python programs covering the concepts taught in the subject.

### Basic Python Programs

Programs demonstrating variables, data types, input, output, and basic operations.

### Conditional Statements

Programs using `if`, `elif`, and `else` to perform decision-making operations.

### Loops

Programs demonstrating `for`, `while`, nested loops, `break`, and `continue`.

### Lists

Programs demonstrating list creation, accessing elements, modifying lists, and common list operations.

### Functions

Programs demonstrating function creation, parameters, arguments, and return values.

### Classes and Objects

Programs demonstrating the basic concepts of classes, objects, attributes, and methods.

### Constructors

Programs demonstrating the use of constructors to initialize objects.

### Inheritance

Programs demonstrating how properties and methods can be inherited between classes.

### Single Inheritance

Demonstrates inheritance between one parent class and one child class.

### Multiple Inheritance

Demonstrates a child class inheriting from multiple parent classes.

### Multilevel Inheritance

Demonstrates inheritance through multiple levels of classes.

### Hierarchical Inheritance

Demonstrates multiple child classes inheriting from a single parent class.

# 🛠️ Requirements

To run the programs, you need:

* Python 3.x
* A Python-compatible IDE or text editor
* Terminal / Command Prompt

Check your Python version:

```bash
python --version
```

or:

```bash
python3 --version
```

---

# ▶️ How to Run

Clone the repository:

```bash
git clone https://github.com/Nikwee-y/Marwadi-Python.git
```

Navigate to the repository:

```bash
cd Marwadi-Python
```

Run a Python program:

```bash
python filename.py
```

On Linux:

```bash
python3 filename.py
```
