## Requirements

The basic programs use Python's standard library. Some programs require additional Python packages or system utilities.

### Python packages

| Package | Used by |
|---|---|
| `mysql-connector-python` | Programs 31–34 |
| `pandas` | Programs 35–36 |
| `matplotlib` | Programs 37–40 |
| `python-whois` | Programs 41–44 |

Install the external Python packages with:

```bash
python -m pip install mysql-connector-python pandas matplotlib python-whois
```

Program 45 also requires the `dig` command, commonly provided by the `bind` utilities package on Linux. MySQL programs 31–34 require a running local MySQL server and a database named `test`.

## How to Run

1. Install Python 3.
2. Open a terminal in the repository directory.
3. Change into the relevant assignment folder.
4. Run a program with Python.

Example:

```bash
cd "Sem 1/Assignment-1"
python 1-Hello.py
```

For another assignment, change the folder name and script filename accordingly. Programs that request input will prompt for it in the terminal.

### Optional: Use a virtual environment

Create and activate a virtual environment from the semester directory:

```bash
python -m venv .venv
source .venv/bin/activate
```

Then install the required packages inside the environment:

```bash
python -m pip install mysql-connector-python pandas matplotlib python-whois
```

To leave the environment:

```bash
deactivate
```

## Notes Before Running

- **Program 4 – Factorial:** The current loop uses `range(1, num-1)`, which does not calculate the standard factorial correctly for most inputs. Review the loop before relying on its result.
- **Program 5 – Fibonacci:** The current sequence starts by printing `1`; it does not print the conventional initial `0`.
- **Program 2 – Arithmetic:** Division and modulus operations need a non-zero second number.
- **Programs 31–34 – MySQL:** The scripts expect a local MySQL server, a database named `test`, and the credentials written in the source files. Program 32 inserts a fixed ID each time it runs; the update and delete scripts depend on the record with ID `1`.
- **Program 28 and 29 – File handling:** `demo.txt` is opened using a relative path, so the file is read from or written to the current working directory.
- **Program 45 – DNS:** The `dig` command must be installed and available in the system PATH.
- **Program 47 – Port scanner:** Run only against systems and IP addresses you own or have explicit permission to test. A port reported as closed means the TCP connection attempt did not succeed; it does not prove that a host is offline.
- **Program 50 – Ping scanner:** The uploaded command uses the letter `l` as the ping count and timeout values. On common Linux `ping` implementations, these should be numeric values, so the program may report every address as down until corrected. The addresses in this script are loopback addresses, not a scan of other devices on the local network.
