## ⚙️ Getting Started

### 1. Requirements

-   Python 3
-   A terminal or code editor
-   Additional packages for selected assignments (listed below)

### 2. Clone the repository

``` bash
git clone https://github.com/Nikwee-y/Marwadi-Python.git
cd Marwadi-Python
```

### 3. Run a program

Move into the relevant assignment folder and run the Python file:

``` bash
cd Assignment-1
python 1-Hello.py
```

Use the appropriate folder and filename for the program you want to run.
Programs that request input will prompt you in the terminal.

### 4. Optional: Create a virtual environment

From the repository root:

``` bash
python -m venv .venv
source .venv/bin/activate
```

Install the additional packages:

``` bash
python -m pip install mysql-connector-python pandas matplotlib python-whois
```

When finished:

``` bash
deactivate
```

## 📦 Additional Requirements

The basic programs use Python's standard library. The following programs
need extra packages or system tools:

  Dependency                 Used by
  -------------------------- -----------------
  `mysql-connector-python`   Programs 31--34
  `pandas`                   Programs 35--36
  `matplotlib`               Programs 37--40
  `python-whois`             Programs 41--44
  `dig` command              Program 45

Program 45 requires `dig`, commonly provided by the `bind` utilities
package on Linux. Programs 31--34 require a running local MySQL server,
a database named `test`, and the credentials configured in the source
files.

## ⚠️ Notes & Known Limitations

These notes describe the current scripts; they do not imply that every
program has been tested or corrected.

-   **Program 2 --- Arithmetic:** Division and modulus require a
    non-zero second number.
-   **Program 4 --- Factorial:** The current loop uses
    `range(1, num-1)`, which does not calculate the standard factorial
    correctly for most inputs.
-   **Program 5 --- Fibonacci:** The current sequence starts by printing
    `1`, rather than the conventional initial `0`.
-   **Programs 31--34 --- MySQL:** These scripts expect a local MySQL
    server, a database named `test`, and credentials written in the
    source files. Program 32 inserts a fixed ID each time it runs; the
    update and delete scripts depend on the record with ID `1`.
-   **Programs 28--29 --- File handling:** `demo.txt` is opened with a
    relative path, so it is read from or written to the current working
    directory.
-   **Program 45 --- DNS:** The `dig` command must be installed and
    available in the system PATH.
-   **Program 47 --- Port scanner:** Use it only on systems and IP
    addresses you own or have explicit permission to test. A failed TCP
    connection does not prove that the host is offline.
-   **Program 50 --- Ping scanner:** The uploaded command uses the
    letter `l` where numeric ping count and timeout values are expected.
    On common Linux `ping` implementations, this may cause every address
    to be reported as down. The addresses used are loopback addresses,
    not other devices on the local network.
